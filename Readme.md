# DevFest Callao 2026 — Dino agenda

Agenda interactiva para tu charla «¿Y si tu interfaz fuera un juego? CSS y JavaScript en acción».

## Importante para la operación del evento

**El navegador no sabe si el speaker empezó realmente.** El modo automático muestra la sesión que debería estar ocurriendo según la programación. Si una charla se adelanta o retrasa, presiona **Manual / En vivo** y después **Iniciar siguiente etapa** cuando comience de verdad (o el botón **Iniciar** en la tarjeta correspondiente). Si te equivocas, usa **Anterior**. El progreso manual se guarda al recargar la página en el mismo navegador. La hora del equipo debe ser correcta para el modo automático.

Al pasar de automático a manual se conserva inicialmente la etapa prevista por el horario. Si la charla real está adelantada o atrasada, usa **Anterior**, **Iniciar siguiente etapa** o **Iniciar** en la tarjeta correcta.
